# Module Map

- `desktop/`: Desktop shell and UX modules
- `android/`: Android companion app and capture/control services
- `backend/`: Application-layer platform services
- `cloud/`: Cloud infrastructure-facing services
- `sdk/`: Developer-facing SDK surfaces
- `plugins/`: First-party and community plugins
- `themes/`: Theme packs and theme assets
- `installer/`: Platform-specific installers
- `website/`: Public-facing web experience
- `design-system/`: UI tokens and design primitives
- `shared/`: Shared contracts, models, and utilities
